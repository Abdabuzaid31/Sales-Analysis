# Sales & Business Performance Analysis

## Project Overview

I built this project using Power BI to analyze sales data and understand business performance across different years, products, and locations.

The report focuses on revenue, profit, and sales trends, with comparisons to the previous year.

## Tools Used

- Power BI Desktop
- Power Query
- DAX

## What I Did

- Cleaned and prepared the data using Power Query.
- Created relationships between the tables.
- Built DAX measures to calculate revenue, costs, profit, and profit margin.
- Calculated year-over-year changes to compare business performance.
- Created charts and KPI cards to display the results.
- Added slicers to filter the report by year.
- Used a map to show profit across different locations.

## Report Overview

The report includes:

- Revenue and profit overview
- Current year vs. previous year comparisons
- Monthly revenue trends
- Profit by product and category
- Profit by city and region
- Interactive year filtering
